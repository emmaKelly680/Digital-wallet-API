A production-oriented RESTful digital wallet API built with TypeScript, Node.js, Express, Prisma, PostgreSQL, JWT, argon2, and Zod.

The project simulates the backend infrastructure behind a digital wallet application, including user authentication, wallet management, balance operations, transactions, authorization, validation, error handling, and security controls.
The main focus areas  of this project are:

Authentication
Authorization
Secure password handling
JWT-based sessions
Input validation
Database transactions
Wallet balance management
Transaction records
Error handling
Rate limiting
Separation of concerns
Repository/service/controller architecture
API testing
Production-oriented backend practices
